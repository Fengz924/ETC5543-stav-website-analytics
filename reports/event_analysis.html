1 Scope and interpretation

This audit reviews the file Webinar_Participants_July_2026.xlsx. The source contains a participant list but no registration date, attendance status, email, member identifier or event identifier. Therefore, this analysis describes the available participant records; it does not calculate registration, attendance or conversion rates.

The exact webinar name and date were not supplied. The reporting label below is therefore taken from the source filename and should be updated when confirmed.

4 Cleaning rules

Cleaning is intentionally conservative. No participant row is deleted and no missing organisation or role is inferred.

participants_clean_internal <- participants_initial |>
  mutate(
    source_row = row_number() + 1L,
    participant_id = str_c("WP202607-", str_pad(row_number(), 3, pad = "0")),
    name_clean = name,
    organisation_school_clean = organisation_school,
    role_subjects_clean = role_subjects,
    organisation_school_missing = is.na(organisation_school_clean),
    role_subjects_missing = is.na(role_subjects_clean),
    profile_complete = !organisation_school_missing & !role_subjects_missing,
    stav_internal = str_detect(
      coalesce(organisation_school_clean, ""),
      regex("^STAV$|Science Teachers.? Association of Victoria", ignore_case = TRUE)
    ),
    source_file = basename(source_file),
    source_sheet = "Webinar Participants",
    reporting_period = "2026-07"
  ) |>
  select(
    participant_id,
    source_row,
    name_clean,
    organisation_school_clean,
    role_subjects_clean,
    organisation_school_missing,
    role_subjects_missing,
    profile_complete,
    stav_internal,
    source_file,
    source_sheet,
    reporting_period
  )

7 Role and subject notes

8 Tracking limitations

  • The file does not distinguish registrants from attendees.
  • No attendance, cancellation, no-show or completion status is available.
  • No event ID, exact event name or exact event date is included.
  • No registration source, campaign, payment or ticket information is included.
  • No email, CRM/member ID or other approved linkage key is available.
  • The file cannot be joined reliably to GA4 or CRM at participant level.
  • Participant names are personal information and are excluded from the analysis-ready output.

9 Recommendations

  1. P1 — Define the record. Confirm whether this workbook represents registrants, attendees, webinar-platform participants, or a manually curated list.
  2. P1 — Add event metadata. Include event ID, event name, event date and event type in every future export.
  3. P1 — Add funnel status. Include registration status, attendance status, cancellation/no-show status and registration timestamp.
  4. P2 — Add an approved linkage key. If privacy and governance permit, use a stable CRM/member or registration ID. Do not use names as the primary join.
  5. P2 — Add acquisition fields. Include registration source, medium, campaign and landing page where available.
  6. P2 — Separate structured fields. Store role, school type, year level and subject areas in separate fields or controlled categories.

11 Audit summary

The source contains 24 participant records and is suitable for a limited description of organisation and role/subject coverage. It is not a complete event-registration dataset. The main data-quality issue is missing context and funnel fields rather than duplicate rows or invalid values. The clean output retains every source record, documents missingness, flags the STAV internal record and removes participant names from the analysis-ready file.

The next analytical step should occur only after STAV confirms what the list represents and provides event metadata plus registration/attendance fields.
